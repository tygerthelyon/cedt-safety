Safety Data Sheets (SDS)

Download SDS files

Safety Data Sheets (SDS) were formerly referred to as Material Safety Data Sheets (MSDS), since they are safety data sheets about a given material. This acronym is still sometimes found on documents or online, but it refers to the same thing.

According to RMM 501, lab supervisors must:

"provide current Safety Data Sheets (SDS) for all hazardous materials used in the workplace."

The supervisor must also:

"maintain an inventory of all hazardous materials used or stored in the workplace using the McMaster web based inventory system. Written inventory records must be maintained in the workplace where the University system is not available."

Safety Data Sheets (SDS) provide technical information about a given chemical. The SDS include properties of the chemical, permissible exposure levels, storage recommendations, instructions for dealing with exposure or spills, and more.

Historically, each lab maintained a physical catalogue of SDS files. It is now sufficient to have access to SDS files via a local computer.
